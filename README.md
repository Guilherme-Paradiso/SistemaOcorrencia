# 📚 Sistema de Ocorrências Escolares

Projeto desenvolvido para a disciplina **Web 3** no IFPE.  
O objetivo é criar uma aplicação web para **registro e gerenciamento de ocorrências escolares**, utilizando **Java com Spring Boot** e boas práticas de arquitetura.

---

## 🚀 Funcionalidades

- Cadastro de ocorrências escolares (alunos, professores, descrição, data)
- Listagem e consulta de ocorrências registradas
- Atualização de informações de ocorrências
- Exclusão de registros
- Interface web com **Thymeleaf**
- Persistência de dados com **JPA/Hibernate**

---

## 🛠️ Tecnologias Utilizadas

- **Java 17+**
- **Spring Boot**
- **Spring Data JPA**
- **Thymeleaf**
- **H2 Database** (para testes)
- **Maven** (gerenciamento de dependências)
- **Arquitetura MVC**
